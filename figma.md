## Как работать в Figma

Обязательно загрузи скиллы **до** вызовов:

- `figma-use` — перед каждым `use_figma`
- `figma-generate-library` — если правишь или добавляешь компоненты
- `figma-generate-design` — если собираешь экраны из библиотеки
- `figma-design-to-code` — если читаешь макет в код через `get_design_context`

Правила API:

- `return` отдаёт результат; не вызывай `figma.closePlugin()` и не используй `figma.notify()`
- цвета 0–1, не 0–255
- шрифт: `loadFontAsync` → `await` → правка текста
- Playfair Display: `Bold`, `SemiBold` (без пробела)
- Inter: `Regular`, `Medium`, `Semi Bold` (с пробелом)
- страницу переключай только через `await figma.setCurrentPageAsync(page)`, один раз за вызов
- `FILL` / `HUG` ставь **после** `appendChild` в auto-layout
- мутации `use_figma` идут последовательно, не параллель
- сначала `search_design_system` + `get_libraries`, потом новые компоненты

Перед созданием чего-либо проверь файл: страницы, variables, component sets. Не дублируй токены и компоненты.

## Визуальные решения v1 (не ломать)

- Только светлая тема. Dark mode нет.
- Интерфейс на русском, имена токенов и компонентов в Figma — английские.
- Радиусы: `radius/none` (0) и `radius/hair` (2). Кнопки, карточки, слоты, модалки — острые. Пилюли запрещены.
- Фото без скругления.
- Розовый (`pink/100`) и персик (`peach/100`) — только декоративный блок **под медиа** на публичных страницах. Не заливка кнопок, не фон абзаца.
- Кнопки: Primary — чёрная заливка, белый текст; Ghost — тонкая чёрная обводка; Text — без рамки; Danger — заливка `danger/500`, белый текст, только «Отменить запись». Подпись не должна касаться края: на лендинге у инстансов паддинг Large 24×16, Medium 16, Small 16×12 (у атома в библиотеке паддинг 0 — не копировать это на экраны).
- Футер — чёрный, текст белый. Хедер минимальный: «Ноготочки» слева, меню справа. Корзины нет. На лендинге, каталогах, карточке мастера, шагах 1–3 записи, проверке гостя, «Резерв истёк», трёх служебных и политике справа «Войти». **На шести auth-фреймах ссылка «Войти» в шапке скрыта** (оверрайд Guest, не вариант LoggedIn и не детач) — не возвращай её, иначе вход зациклится. Primary «Войти» в форме — другое. На «вход выполнен», «Готово», «Слот занят» и одиннадцати фреймах кабинета — Auth=LoggedIn («Кабинет» вместо «Войти»).
- Тени почти нет. `Shadow/Soft` только у Modal и выпадающего Select.
- Тон спокойный, на «вы». Без «Ура!!!», скидок, золота, сердечек, скриптовых шрифтов.

## Токены

Коллекции:

| Коллекция | Режим | Назначение |
|---|---|---|
| Primitives | Value | сырые hex, scopes скрыты |
| Color | Light | semantic aliases |
| Spacing | Value | 2…128 |
| Radius | Value | none / hair / full |
| Typography Primitives | Value | семейства, веса, кегли |
| Typography | Value | semantic aliases |

Ключевые semantic-цвета:

- `color/bg/canvas`, `color/bg/subtle`, `color/bg/inverse`, `color/bg/accent`, `color/bg/accent-soft`
- `color/text/primary`, `secondary`, `muted`, `inverse`, `danger`, `success`
- `color/border/default`, `subtle`, `focus`, `danger`, `disabled`
- `color/fill/primary`, `primary-text`, `ghost`, `disabled`, `hover`
- `color/fill/slot-available`, `slot-selected`, `slot-unavailable`, `slot-reserved`
- `color/status/pending`, `confirmed`, `cancelled`, `expired`

WEB code syntax: `var(--color-bg-canvas)` и аналоги. Новых raw hex в компонентах не заводи — только alias на primitive.

Сетка: desktop 1440 / 12 колонок / gutter 24 / margin 80. Tablet 768 / 40. Mobile 390 / 20. Touch target ≥ 44px. Контраст текста ≥ 4.5:1.

## Контентные запреты

- Не выдумывать ФИО мастера. Нет имени → «Мастер студии».
- Не выдумывать телефон, email, полный адрес. В публичной части — «центр города». Точный адрес — только после подтверждённой записи, строкой Meta, не картой.
- Цены и длительности только из паспорта. Не добавлять скидки.
- Оплаты на сайте нет. Статусы: ожидает предоплату / подтверждена / отменена / перенесена / истекла. Нет корзины, checkout, платёжных полей.
- Сертификат в каталоге — прайс, не запись. Дизайн ногтей — добавка. Гость подтверждает запись только после входа. Точный адрес — в кабинете при статусе «подтверждена».
- Нет выезда на дом, админки, чата, отзывов-карусели, карт.

Обязательные empty/error (уже есть в `Empty State` / `Banner` / `Alert`). Куда ставить на экране — `Путь клиента.md`, §9:

- пустой кабинет → `EmptyCabinet` + «Записаться»
- нет слотов → `NoSlots` на шаге даты, другой мастер / другая дата
- резерв истёк → `ReserveExpired`, начать запись снова
- слот занят → `SlotTaken`, другое время
- 404 → `NotFound`, на главную
- сервер недоступен → `ServerError`, попробовать ещё раз
- ошибка входа — `Alert` в форме, не полноэкранный empty
- сессия истекла — `Empty State / SessionExpired` + CTA «Войти»
- сертификат в каталоге — `Banner / Neutral`, не степпер
- гость на проверке записи — `Banner / Neutral` + вход / регистрация

## Известные шероховатости

- Дефолтный `Label` у кнопок — «Сохранить». На экранах меняй текст инстанса: «Записаться», «Записаться к мастеру», «Подтвердить запись», «Отменить» и т.д. У части Empty State CTA ещё дефолтный «Сохранить» — на экране подставляй действие контекста.
- У атомов `Button/*` паддинг 0: длинная подпись садится на обводку. На лендинге паддинг задан оверрайдом инстанса. На следующих экранах повторяй тот же зазор, библиотеку ради этого не пересобирай, пока человек не попросит починить атом.
- `Media Frame` в библиотеке 240×340. На лендинге инстанс масштабирован (~480×680), на карточке мастера — ~400×567. Мастер-компонент не менять.
- Вложенный `Avatar` у `Master Card` Identity=Unnamed жмёт ширину (~30×80, HUG по инициалам). `resize` на вложенном инстансе не берётся. На лендинге, каталоге мастеров и шаге 2 записи портрет 80×80 собран локально, штатный Avatar скрыт. На `Master — Карточка` крупный портрет — `Media Frame`, Avatar у Unnamed тоже скрыт. Библиотеку из-за этого не чинить, пока человек не попросит.
- Loading у кнопки и `Spinner` — дуга (arc).
- Компоненты лежат одной длинной колонкой на `Components`. Не разносить по файлам и не переименовывать наборы без причины.
- Спесимены Auth / Slot errors — документация сборки, не готовые экраны.
- У `Footer` вложенные колонки имеют белую заливку и перекрывают inverse-текст. На каталогах, карточке мастера, auth-фреймах, шагах 1–5 записи, одиннадцати фреймах кабинета, трёх служебных и политике заливки сняты оверрайдом инстанса (клон футера каталога). Лендинг и мастер-компонент не трогать, пока человек не попросит починить атом.
- Клон `Master row` с лендинга в HUG-колонку не даёт родителю высоту: `Main` сжимается до intro+паддинг, `clipsContent` режет карточки в Present. На `Catalog — Мастера` это уже поправлено (FIXED 593, clip снят). На следующих экранах с тем же клоном сразу FIXED/`HUG` после явного `resize`, не клипать коротким родителем.
- `Radio` в HUG: подписи «Выбран» и «Выбрать» разной ширины, портрет и карточка выбранного мастера уезжают на ~8px. На `Booking — 2 Мастер` радио обёрнуто в локальный `Radio slot` FIXED **124**. На следующих списках с Radio + контент сразу фиксируй колонку выбора, атом не пересобирай.
- `Nav Header` Guest всегда несёт слой «Войти». На auth-фреймах он скрыт оверрайдом инстанса; в дереве слой может не отображаться, пока скрыт. Не включай его снова и не переключай эти шапки в LoggedIn (появится «Кабинет»). На лендинге, каталогах, карточке мастера, шагах 1–3 записи, проверке гостя, «Резерв истёк», трёх служебных и политике «Войти» оставь. На «вход выполнен», «Готово», «Слот занят» и одиннадцати фреймах кабинета — Auth=LoggedIn («Кабинет»).
- Атом `Calendar` рисует дни обычным текстом, не инстансами `Calendar/Day`. На шаге 3 и на кадрах переноса selected/unavailable — оверрайды заливки на инстансе.
