# C10. Вход через Яндекс

- **ID:** C10
- **Статус:** pass
- **Дата:** 2026-09-21T19:20:00Z
- **База:** https://nogotochki-test.ru
- **Что сделали:** На `auth.html` нажали «Войти с Яндекс ID» → согласие в Яндексе → callback на `https://nogotochki-test.ru/auth/yandex/callback`. Отдельно проверены пути отмены/ошибки (`error=access_denied`, без `code`, невалидный `code`).
- **Ожидали:** согласие → кабинет (или проверка записи с холдом); «Отмена» / ошибка Яндекса → вход с понятным сообщением, без тихого успеха.
- **Увидели:**
  - Кнопка «Войти с Яндекс ID» видна; `GET /api/auth/yandex/start` → 302 на `oauth.yandex.ru/authorize` с `redirect_uri=https://nogotochki-test.ru/auth/yandex/callback`.
  - После согласия — кабинет (empty или список записей); cookie `session` Secure + HttpOnly; `/api/auth/me` 200.
  - Отмена / ошибка Яндекса → `auth.html`, alert «Вход через Яндекс не завершён…»; сессии приложения нет (`/api/auth/me` 401).
- **Заметки:** Env `YANDEX_CLIENT_*` / `YANDEX_REDIRECT_URI` на сервере заданы; callback на https-домене. Успешный путь согласие → кабинет принят как пройденный.
